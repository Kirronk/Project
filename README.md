Проект, сделанный по заказу психотерапевтического отдела

Проект включает в себя программу, работающая с данными пациентов и включающая их в одну систему. Реализовано на Tkinter с применением SQLite таблицы

Структура файлов:
- main.py - сборка и запуск приложения
- database.py - подключение базы данных
- patients.db - база данных
- requirements.txt - список зависимостей
- ui/app.py - главный скрипт приложения
- ui/date_widgets.py - виджет календаря
- planning.py - функции планирования
- repositories.py - работа с базой данных
- validation.py - функции проверки введённых значений
